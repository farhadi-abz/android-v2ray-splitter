# V2Ray Extractor (اندروید)

اپلیکیشن ساده‌ی اندرویدی برای استخراج و تبدیل کانفیگ‌های V2Ray/Trojan از یک لینک سابسکریپشن (Subscription) به لینک‌های استاندارد قابل استفاده در کلاینت‌هایی مثل v2rayNG.

## توضیح پروژه

بسیاری از سرویس‌های سابسکریپشن، لیست کانفیگ‌ها را به‌صورت یک آرایه‌ی JSON (فرمت سینگ‌باکس/v2ray) برمی‌گردانند که مستقیماً توسط اکثر کلاینت‌ها قابل import نیست. این اپلیکیشن این فایل JSON را دانلود می‌کند، هر کانفیگ را تجزیه می‌کند و از آن یک لینک استاندارد (`vless://...` یا `trojan://...`) می‌سازد که می‌توانید کپی کرده و در هر کلاینت V2Ray استفاده کنید.

## قابلیت‌ها

- دریافت لیست کانفیگ‌ها از یک لینک سابسکریپشن
- پشتیبانی از پروتکل‌های **VLESS** و **Trojan**
- تشخیص خودکار تنظیمات انتقال (`network`) شامل حالت `ws` (WebSocket) و استخراج `path` و `host`
- پشتیبانی از TLS و استخراج `SNI` از تنظیمات
- نمایش نام هر کانفیگ (`remarks`) در یک لیست
- کپی سریع هر لینک با یک لمس روی آیتم مربوطه در لیست

## نحوه‌ی کارکرد (مکانیزم داخلی)

1. کاربر لینک سابسکریپشن را در کادر ورودی وارد می‌کند.
2. اپلیکیشن با `OkHttp` و هدر `User-Agent: v2rayNG/1.8.5` یک درخواست GET به آن آدرس می‌زند (این هدر برای سازگاری با سرویس‌هایی است که خروجی را بر اساس نوع کلاینت تغییر می‌دهند).
3. پاسخ به‌صورت یک `JSONArray` از آبجکت‌های کانفیگ پردازش می‌شود.
4. برای هر کانفیگ:
   - مقدار `remarks` (نام کانفیگ) استخراج می‌شود.
   - در آرایه‌ی `outbounds`، اولین موردی که تگ آن `proxy` باشد یا پروتکلش `vless`/`vmess`/`trojan` باشد پیدا می‌شود.
   - بر اساس پروتکل، آدرس، پورت و شناسه/رمز عبور استخراج می‌شود.
   - پارامترهای انتقال (`type`, `security`, `path`, `host`, `sni`) به‌صورت query string به لینک اضافه می‌شوند.
   - در نهایت یک لینک استاندارد به‌فرمت `protocol://id@address:port?params#remarks` ساخته می‌شود.
5. تمام لینک‌های ساخته‌شده در یک `ListView` نمایش داده می‌شوند.
6. با لمس هر آیتم، لینک مربوطه در کلیپ‌بورد گوشی کپی می‌شود تا مستقیماً در کلاینت V2Ray وارد (Import) شود.

> توجه: در پیاده‌سازی فعلی فقط پروتکل‌های `vless` و `trojan` به‌صورت کامل تبدیل می‌شوند؛ سایر پروتکل‌ها (مانند `vmess`) در حال حاضر پشتیبانی نمی‌شوند.

## پیش‌نیازها

- Android Studio (نسخه‌ی جدید)
- JDK 11
- Android SDK با `minSdk 24` و `targetSdk 36`
- اتصال اینترنت روی دستگاه/شبیه‌ساز (برای دریافت لینک سابسکریپشن)

## نصب و اجرا

```bash
git clone https://github.com/farhadi-abz/android-v2ray-splitter.git
cd android-v2ray-splitter
```

سپس پروژه را در Android Studio باز کرده و روی دستگاه یا شبیه‌ساز اجرا کنید، یا از طریق خط فرمان:

```bash
./gradlew installDebug
```

## نحوه‌ی استفاده

1. اپلیکیشن را باز کنید.
2. لینک سابسکریپشن خود را در کادر بالای صفحه وارد کنید.
3. روی دکمه‌ی «دریافت لیست کانفیگ‌ها» بزنید.
4. از لیست نمایش داده‌شده، روی هر کانفیگ که می‌خواهید بزنید تا لینک آن کپی شود.
5. لینک کپی‌شده را در کلاینت V2Ray خود Paste/Import کنید.

## ساختار پروژه

```
app/
 └── src/main/java/com/example/v2raylinkmaker/
     └── MainActivity.kt   ← تمام منطق برنامه (دریافت، پارس، تبدیل، نمایش، کپی)
 └── src/main/res/layout/
     └── activity_main.xml ← رابط کاربری ساده (ورودی لینک + دکمه + لیست)
```

## وابستگی‌ها

- [OkHttp 4.12.0](https://square.github.io/okhttp/) برای درخواست‌های شبکه
- کتابخانه‌ی `org.json` (داخلی اندروید) برای پارس JSON

## محدودیت‌های شناخته‌شده

- فقط پروتکل‌های VLESS و Trojan به‌طور کامل تبدیل می‌شوند.
- در صورت خطا در پارس یک کانفیگ خاص، فقط همان کانفیگ نادیده گرفته می‌شود و در Logcat با تگ `V2RAY_CONVERT` ثبت می‌شود.
- ترافیک با `usesCleartextTraffic="true"` مجاز است تا لینک‌های سابسکریپشن HTTP هم کار کنند.
